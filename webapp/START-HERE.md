## ❓ Troubleshooting

**Video won't play?**
- The streaming source may be down temporarily
- Try a different movie
- Check internet connection

**No posters/images?**
- You need the TMDB API key (see above)
- Works fine without it, just no images

**Want more movies?**
- Add the API key for full TMDB catalog
- Or browse the popular section (already curated)
